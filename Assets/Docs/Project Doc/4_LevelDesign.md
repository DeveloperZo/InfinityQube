Act 1: Learn the Rules (Stages 0-2)
Establishing the core loop and primary danger
Stage 0: Pure Fundamentals

Grid: 5x15
Tools: Movement + Individual Markers (unlimited)
Cubes: Normal only  + Black
The Foundation: Learn timing, prediction, and the satisfaction of capture. Simple patterns build confidence. No danger yet - just pure execution.

Wave 0_01 - 2 rows with 1 black cube on each row
Wave 0_02 - 2 rows with 2 black cubes on each row
Wave 0_03 - 2 rows with 3 black cubes on each row

Stage 1: The First Rule - Death Exists

Grid: 5x18
Tools: Individual Markers (unlimited)
Cubes: Normal + Black
The Lesson: Black cubes introduced in the simplest possible way - single black cube in center lane while player learns to dodge. Then mixed patterns where black cubes create "no-go" lanes. The message is crystal clear: Black = Death.

Wave 1_02 - 3 rows with 1 black cubes on each row
Wave 1_02 - 3 rows with 2 black cubes on each row
Wave 1_03 - 3 rows with 3 black cubes on each row

Stage 2: Dancing with Danger

Grid: 5x20
Tools: Individual Markers (5 charges)
Cubes: Normal + Black
The Skill: Black cubes now weave through normal patterns. Players learn to read the board holistically - planning safe movement while setting up captures. Resource limit adds pressure to make every marker count.


Act 2: Efficiency Under Pressure (Stages 3-5)
Learning to handle density while avoiding death
Stage 3: The Squeeze

Grid: 7x22 (wider but more dangerous)
Tools: Individual Markers (3 charges only)
Cubes: Normal + Black
The Problem: Dense formations with black cubes mixed in. Individual markers can't handle the volume. Players feel the walls closing in - they NEED something more efficient.

Stage 4: Area Control Revolution

Grid: 7x24
Tools: Individual (3) + Area Markers (2)
Cubes: Normal + Black
The Relief: Area markers transform impossible situations into manageable ones. But black cubes in formations mean careful positioning - one wrong area marker could waste resources on uncapturable cubes.

Stage 5: The Blue Solution

Grid: 7x26
Tools: Individual (2) + Area (2)
Cubes: Normal + Black + Blue
The Power-Up: Blue cubes introduced as the "anti-black" - they're valuable and create detonations. First waves show blue cubes clearing paths through normal clusters. Players learn: Black = avoid, Blue = pursue.


Act 3: Advanced Tactics (Stages 6-8)
Mastering complex interactions
Stage 6: Chain Reactions

Grid: 9x28
Tools: All previous
Cubes: All types
The Combo: Blue cubes positioned to create chain clearings. Black cubes threaten to ruin perfect setups. Players learn to see multiple moves ahead - "If I capture this blue, the detonation will clear those normals before the black cube blocks the lane."

Stage 7: The Wall

Grid: 9x30
Tools: All previous
Cubes: All types + Reinforced
The Puzzle: Reinforced cubes (2-3 hits) create barriers. Black cubes prevent direct assault. Players must use blue cube detonations to soften reinforced cubes from safe distances.

Stage 8: Resource Management Master Class

Grid: 9x32
Tools: All previous (very limited charges)
Cubes: All types
The Test: Brutal resource constraints force perfect play. Every marker must count. Black cubes punish waste. Blue cubes become precious opportunities for efficiency.


Act 4: Environmental Hazards (Stages 9-10)
The board itself becomes dangerous
Stage 9: Corrupted Earth

Grid: 9x35
Tools: All previous
Cubes: All types
Tile States: Normal + Corrupted
The Escalation: Corrupted tiles make ANY cube passing over them temporarily act like black cubes. Safe cubes become dangerous based on position. The board itself is now an enemy.

Stage 10: Risk and Reward

Grid: 11x38
Tools: All previous + Tile State Changer (1 use)
Cubes: All types
Tile States: All types (Corrupted + Enhanced)
The Choice: Enhanced tiles supercharge captures but are often near corrupted tiles. Players face constant risk/reward decisions. The tile state changer becomes a crucial strategic tool.


Act 5: Mastery Test (Stages 11-12)
Bringing it all together
Stage 11: Chaos Control

Grid: 11x42
Tools: All tools (balanced limits)
Cubes: All types
Tile States: Dynamic (changing during waves)
The Pressure: Everything players learned, but faster and more complex. Tile states shift during waves. Black cubes force constant movement. Blue cubes offer fleeting opportunities.

Stage 12: The Final Exam

Grid: 11x50
Tools: Precise allocations per wave
Cubes: All types
The Ultimate Test:

Wave 1: "The Maze" - Black cubes create complex navigation puzzle
Wave 2: "The Swarm" - Overwhelming density requiring perfect blue cube usage
Wave 3: "The Dance" - Everything in elegant, brutal harmony
